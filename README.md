# Proceso de Automatización Recepción y Generación de Facturas.
Proyecto CAPSTONE 005
Aplicación web que permite centralizar y administrar las solicitudes de emisión de facturas recibidas desde distintos canales de comunicación. El sistema registra los datos de cada solicitud, identifica el canal de origen (ya sea correo electrónico o WhatsApp), aplica validaciones sobre los campos obligatorios, controla el estado del trámite y genera un historial medible de las acciones realizadas por los usuarios dentro de la aplicación.
